The installer includes runtime tools downloaded during the release build.

https://ffmpeg.org/legal.html
https://github.com/GyanD/codexffmpeg

yt-dlp
------
The Python package is bundled into LiveCatchWorker.exe from the pinned
yt-dlp dependency in requirements.txt. yt-dlp is licensed under The Unlicense.
https://github.com/yt-dlp/yt-dlp

Deno
----
Deno is an optional JavaScript runtime used by yt-dlp for supported sites. The
Windows binary is downloaded from the official Deno release page:
https://github.com/denoland/deno/releases

LiveCatch itself is provided under the license in the installed LICENSE file.
